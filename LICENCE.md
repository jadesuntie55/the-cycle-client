## 🧩 About

**The Cycle Frontier Client** is a comprehensive game client for The Cycle Frontier featuring overlay, ESP, loot tracker, recoil control, safe-mode toggles, and match statistics.

Based on popular tools like **TCF Overlay**, **Cycle Companion**, and **Frontier QOL**.

---

## ✨ Features

### 🎮 Core Features
- Overlay — in-game HUD with live match info
- ESP — highlight players, loot, and extract points
- Loot Tracker — track collected items and value
- Recoil Control — stabilize weapon spread
- Match Stats — view kills, damage, and survival time

### 🎨 Interface & Unlocks
- Custom HUD — rearrange overlay widgets freely
- Theme Support — switch between dark and light themes
- Hotkey Manager — rebind every action in-game

### 🏋️ Practice & Training
- Safe Mode — restrict risky features automatically
- Session Logs — review past matches and outcomes
- Loadout Presets — save and switch gear setups quickly
- Offline Range — practice aim on a local map
